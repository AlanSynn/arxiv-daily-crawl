# Archived Papers

This directory contains archived papers that are older than 1 year from the CV Arxiv Daily collection.

Archives are organized by month, with each month's archive containing papers that were moved during that month.

## Available Archives

Archives will be listed here automatically as they are created.

## About the Archiving Process

Papers are automatically archived when they are older than 365 days (1 year) from their publication or last update date. This helps keep the main collection current while preserving older papers for reference.

The archiving process runs monthly and is automated via GitHub Actions.

To browse the current papers collection, please go back to the [main page](../index.md).
